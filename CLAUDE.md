# INFOTECH website

Next.js 15 (App Router) + Tailwind CSS v4 marketing site for INFOTECH, an AI automation agency for service businesses.

## Where things live
- `src/lib/site.ts`: name, booking link, email, domain, commercial terms. **Placeholders must be replaced before launch.** The contact form posts to Formspree using `NEXT_PUBLIC_FORMSPREE_ID` and falls back to mailto when it's unset.
- `src/lib/content.ts`: all copy (services, industries, steps, pricing, FAQs, and `serviceDetails` for the `/services/[slug]` pages). Edit words here, not in components.
- Reviews copy must never filter who is asked for a review (review gating breaks Google and FTC rules).
- `src/app/globals.css`: brand tokens (light and `.dark`). Custom classes sit in `@layer components` so Tailwind utilities can override them. Keep it that way.
- `src/components/brand.tsx`: wordmark (traced from the logo) and the diamond mark.
- `public/images/`: Unsplash photos (Unsplash License; credit line is in the footer).

- The offer is a **free audit** (`audit` in `site.ts`). Every booking button is `<AuditButton>` (`src/components/audit.tsx`) and goes to `/contact` with context (`auditHref({ plan, industry, from, loss })`). Once `bookingUrl` is real, `/contact` shows the calendar inline; until then it shows the request form. Successful requests go to `/thanks`.
- Phones get a sticky booking bar (`mobile-audit-bar.tsx`) and a "Free audit" button in the top bar. Enquiries carry the visitor's first landing page, referrer and UTM tags (`attribution.tsx`).
- GSAP-pinned sections sit inside a React-owned wrapper and clean up in `useLayoutEffect`; without both, navigating away from the homepage crashes the next page.
- `src/lib/formspree.ts`: shared Formspree submit + mailto fallback, used by the contact form and the calculator's estimate capture.
- `src/components/analytics.tsx`: Vercel Web Analytics plus "Booking click", "CTA click", "Contact form sent" and "Estimate requested" events.
- `src/components/json-ld.tsx`: schema.org data (Organization, WebSite, FAQPage, Service list, pricing offers).
- `src/app/opengraph-image.tsx`, `apple-icon.tsx`: generated share image and app icon.

- Trust sections (`src/components/trust.tsx`): AI demo (call number and/or recording with transcript), guarantee, company details and case studies. Each is driven by `trust` in `site.ts` or `caseStudies` in `content.ts` and stays hidden while empty. Never fill them with invented data.

- Tool logos: full-colour SVGs in `public/logos`, generated by `node scripts/build-logos.mjs` (gilbarbara/logos and Simple Icons, both CC0). Tools without a free logo show their name only; never draw a look-alike.
- `src/lib/guides.ts`: articles for `/resources/[slug]`. General information only; the consent guide carries a not-legal-advice note.
- `exampleUsage` in `content.ts`: the labelled example usage figures shared by Pricing and the cost comparison.
- Share images: `src/lib/og.tsx` renders the branded card; each page folder has an `opengraph-image.tsx` with its own title.
- Photos: every image in `public/images` is used exactly once. Keep it that way when adding pages.
- Product mockups (`src/components/product-mockups.tsx`) and example chats use made-up names and numbers and are labelled "Example".

## Brand rules
- Crimson `#CB3A51` (logo), `--crimson-ink` for crimson text on light grounds. Black `#000` matches the logo ground.
- Newsreader for display, Hanken Grotesk for body. Sentence case, no all-caps eyebrows.
- Voice: premium and plain. No hype words ("unlock", "leverage", "seamless"). No invented clients, testimonials or stats.
- Every page opens on a dark hero; the header starts light-on-dark and turns solid on scroll.

## Motion
GSAP ScrollTrigger + Lenis. Pinned "How it works", horizontal industry slider and word-reveal run only at ≥1024px with no reduced-motion preference; otherwise they fall back to stacked layouts.

## Commands
```bash
npm run dev
npm run build
npm run lint
npm test          # Playwright smoke tests over every sitemap page (run after npm run build)
BASE_URL=https://infotech-website-sandy.vercel.app npm test   # same tests against the live site
```

GitHub Actions (`.github/workflows/checks.yml`) runs lint, type check, build and the tests on every push and pull request.

Skills for this project are in `.claude/skills/` (see its README), including Impeccable (`/impeccable audit`, `/impeccable critique`, `/impeccable polish` and more) and its design-check hooks in `.claude/settings.json`. What is left before launch is tracked in `LAUNCH-CHECKLIST.md`.
